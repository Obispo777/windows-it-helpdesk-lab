# Windows IT Help Desk Lab

## About This Project

This repository documents hands-on IT support and Windows administration practice performed in a virtual machine.

The purpose of this project is to develop practical skills that can be applied to an entry-level help desk or IT support position.

## Environment

- Windows 11 Virtual Machine
- Command Prompt
- PowerShell
- Windows Administrative Tools
- Local Users and Groups
- Group Policy
- File and Folder Permissions
- Network Troubleshooting
